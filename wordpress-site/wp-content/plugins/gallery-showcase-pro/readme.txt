Gallery Showcase Pro plugin allows you to manage, edit, design and create new galleries showcases or teasers.


== Description ==

Gallery Showcase Pro is an excellent WordPress plugin to showcase your WordPress gallery in a good presentation view. It is also responsive, retina-ready, and supports lazy loading for lightning-fast photo galleries.

The Pro version of this plugin will compatibility with custom post type and also provide a category filter with multiple design options.

This plugin will help you create custom galleries such as image gallery, photo album, portfolio showcase, and simple picture to an image slider, image carousel, etc., with up to 6 columns. This pro gallery plugin represents a perfect solution for your website.

<strong>[Documentation](https://www.techeshta.com/docs/gallery-showcase-for-wordpress/?utm_medium=wp.org&utm_source=wordpressorg&utm_campaign=readme&utm_content=techeshta)</strong>

### Brand New Concept for Custom Image Size

Generally, we face an issue with image size while showcasing a gallery on the front-end or website because we had different image sizes. We worked with thumbnail settings to provide an option to choose a custom size. You can easily set input width and height for image cropping and select a checkbox for hard cropping.

== Installation ==

<strong>From Your WordPress Dashboard</strong>

1. Go to Plugins ><strong>Add New</strong>
2. Search for <strong>Gallery Showcase Pro For WordPress</strong>
3. Click on <strong>Install Now</strong> Button
4. Click on <strong>Activate Now</strong> After Installed in the Backend
